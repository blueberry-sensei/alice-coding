# Session digest template

Copy thành `YYYY-MM-DD-<chủ-đề>.md`, điền compact, rồi thêm 1 dòng vào `INDEX.md`.
Trong phiên, **cập nhật đè lên chính file này** ở mỗi checkpoint — đừng tạo file mới mỗi lần.

```md
# [YYYY-MM-DD] <chủ đề phiên>

## Bàn về gì
<1–3 gạch đầu dòng: vấn đề/mục tiêu của phiên.>

## Quyết định & lý do
- <quyết định 1> — vì <lý do/đánh đổi>. → đã ghi thành `D-XXXX` nếu là luật bền.
- <quyết định 2> — ...

## Đã làm
<Việc đã hoàn thành, file/khu vực chính, module tag.>

## Trạng thái & luồng còn mở
- <đang dở / chờ / rủi ro chưa xử lý>
- <câu hỏi còn treo cho Bệ hạ>

## Nếu bị auto-compact, đọc lại từ đây
<Điểm tiếp tục chính xác: đang ở bước nào, file nào đang sửa dở, giả định nào đã loại trừ.
Viết cho "chính mình sau khi mất trí nhớ" — người đọc không còn ký ức nào ngoài dòng này.>

## Con trỏ
- Changelog liên quan: <...>
- Mistakes phát sinh: <`M-XXXX`>
- Decisions phát sinh: <`D-XXXX`>
- Wiki cập nhật: <...>
```
