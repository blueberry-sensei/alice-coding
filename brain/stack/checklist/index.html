🤍 ALICE CODING — Checklist cài đặt

Bộ não ký ức cho Alice. Làm lần lượt; tick để lưu tiến độ (ngay trên máy).

0. Yêu cầu 1 lần

Docker Desktop đang chạy. (Tùy chọn) một agent desktop: Claude Desktop hoặc Codex Desktop để chạy INITIALIZATION.

1. Khởi động stack — 1 lệnh

Từ thư mục gốc project (nơi đã pull ALICE CODING vào):

Windows:  powershell -File knowledge\brain\stack\brain-up.ps1
mac/Linux: bash knowledge/brain/stack/brain-up.sh

Docker CE trong WSL: chạy lệnh mac/Linux bên trong WSL. Docker Desktop: lệnh nào cũng được.

Lần đầu sẽ build stack + tải model bge-m3 (vài phút). Chờ tới khi services healthy.

2. Mở app ALICE → tạo danh tính

Vào http://localhost:3000, nhập tên (vd Alice) để tạo local identity.

3. Đặt credential LLM trong app

Settings → Models: chọn provider & dán key. Đề xuất AIStudio (Gemini) free — lấy key tại aistudio.google.com/apikey. (Hoặc OpenRouter free.)

Embedding bge-m3 đã bundle sẵn chạy local trong stack — không cần cấu hình gì cho embedding.

4. Kiểm tra nhanh (embedding + LLM chạy)

Trong app: tạo 1 source thử → thêm 1 đoạn text → đợi trạng thái Ready → search thử. Thấy kết quả = OK.

Nếu document kẹt / FAILED → xem mục Trục trặc bên dưới.

5. Nối "não" vào agent (MCP)

Mount Knowledge MCP vào Claude/Codex: URL http://localhost:8000/mcp/, header Authorization: Bearer <TOKEN>. Lấy token + cách mount: xem knowledge/brain/SETUP.md.

6. Chạy INITIALIZATION Claude/Codex desktop

Mở agent desktop trong repo project, bảo: “Đọc và chạy knowledge/INITIALIZATION.md”. Agent sẽ tinh luyện repo → folder knowledge/ rồi ingest vào não.

7. Code luôn 🚀

Dùng vibe base-prompt đã bake (INITIALIZATION Bước 6 in ra) cho mọi task. Alice tự nạp ký ức (A), sống qua auto-compact (B), tự cải thiện qua /knowledge (C).

Trục trặc thường gặp
Document FAILED khi extract: LLM không phát JSON đúng schema → đổi sang AIStudio/Gemini, hoặc giảm concurrency.
Search không ra / embedding lỗi: kiểm container embedding đã healthy chưa (docker compose logs embedding); model bge-m3 tải xong chưa.
Đổi model embedding sau khi có data: chạy lại python knowledge/brain/sync/sync.py --rebuild.
File tĩnh, self-contained. Tiến độ lưu trong trình duyệt (localStorage). Chi tiết kỹ thuật: knowledge/brain/README.md.
